# João Pedro Varela Borges

Desenvolvedor de Software Júnior na Memora e cofundador da [Lexum](https://www.lexum-ia.com/).

Trabalho com backend Java e soluções de inteligência artificial. Minha experiência reúne desenvolvimento de aplicações, integração com bancos de dados e uso de IA em produtos para resolver problemas concretos.

## Experiência

- **Memora:** desenvolvimento com Java, Spring Boot e Angular, utilizando Oracle e PostgreSQL.
- **Sinerji:** contribuição para o Compras IA, produto voltado a licitações públicas, com construção de prompts para enriquecimento de textos e desenvolvimento e manutenção de funcionalidades.
- **SEEC/DF:** manutenção e evolução do Sisaf da DF Legal, com Java, JPA, JDBC, JSF, PrimeFaces e PostgreSQL.

## Construindo a Lexum

Desde outubro de 2026, construo com outros profissionais um ecossistema de IA para escritórios de advocacia. Além do site institucional, desenvolvo orquestradores de IA com **LangChain4j** e um **anonimizador de PDFs com apoio de IA** para tratar informações sensíveis.

O produto está em desenvolvimento, na etapa de conclusão da demonstração.

## Tecnologias

**Interfaces:** Angular, JSF e PrimeFaces.  
**Dados:** SQL, PostgreSQL e Oracle.
